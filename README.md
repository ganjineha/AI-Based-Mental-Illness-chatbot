# AI-Based Mental Illness Chatbot

An AI-based mental wellness chatbot built using Python and Flask.  
The application provides users with a conversational interface to discuss their feelings and receive supportive responses.

## Features

- 💬 Interactive chatbot interface
- 🤖 AI-powered conversational responses
- 🌐 Flask-based web application
- 🎨 Simple and user-friendly interface
- ⚡ Lightweight and easy to run locally

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- AI/LLM API
